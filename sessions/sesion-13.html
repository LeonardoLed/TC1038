Algoritmo · Pseudocódigo

    REPETIR 20 VECES
        AGREGAR ALEATORIO(1, 6) A resultados
    FIN REPETIR
    MOSTRAR resultados
FIN
Python · Ejemplo / punto de partida
import random
resultados = []
for _ in range(20):
    resultados.append(random.randint(1, 6))
print(resultados)
print(f"Máximo: {max(resultados)}")

Casos de prueba / comprobación
