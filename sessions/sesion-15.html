Del algoritmo a Python

Algoritmo · Pseudocódigo
INICIO
    tablero <- matriz de 3 x 5 con "."
    tablero[1][2] <- "X"
    PARA cada fila EN tablero HACER
        MOSTRAR fila
    FIN PARA
FIN
Python · Ejemplo / punto de partida
tablero = [["." for _ in range(5)] for _ in range(3)]
tablero[1][2] = "X"
for fila in tablero:
    print(" ".join(fila))
