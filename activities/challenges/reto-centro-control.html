Funciones

Reto · Centro de control

Organiza cálculos de una misión/viaje mediante funciones.

Objetivo

Aplicar el contenido del módulo en un problema pequeño que puedas explicar, modificar y probar. No se busca copiar una solución terminada: primero diseña el algoritmo y después implementa.

Antes de programar

Pseudocódigo 
FUNCIÓN convertir_km_millas(km)
    RETORNAR km * 0.621371
FIN FUNCIÓN

PROBAR convertir_km_millas(0) = 0
PROBAR convertir_km_millas(1) ≈ 0.621371

Punto de partida en Python

Python 
def convertir_km_millas(km):
    return km * 0.621371

assert convertir_km_millas(0) == 0
assert abs(convertir_km_millas(1) - 0.621371) < 1e-6
print("Pruebas superadas")

Modifica el programa; agrega validaciones y prueba casos que no estén incluidos en el ejemplo.

Casos de prueba

Diseña al menos tres casos: normal, frontera y un valor que te ayude a detectar errores.

Entrega / evidencia

  • Código Python ejecutable.
  • Al menos tres casos de prueba.
  • Una explicación breve del algoritmo usado.
  • Una mejora propia respecto al punto de partida.
