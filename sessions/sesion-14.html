Del algoritmo a Python

Algoritmo · Pseudocódigo
INICIO
    LEER lista_puntajes
    mayor <- primer_elemento
    PARA cada puntaje EN lista_puntajes HACER
        SI puntaje > mayor ENTONCES mayor <- puntaje
    FIN PARA
    MOSTRAR mayor
FIN
Python · Ejemplo / punto de partida
puntajes = [120, 85, 230, 170, 95]
mejor = puntajes[0]
for p in puntajes:
    if p > mejor:
        mejor = p
print(f"Mejor puntaje: {mejor}")
