Python · Ejemplo / punto de partida
import random

def lanzar_dados(n):
    return [random.randint(1, 6) for _ in range(n)]

resultados = lanzar_dados(1000)
for cara in range(1, 7):
    print(cara, resultados.count(cara))

Casos de prueba / comprobación

Comprueba que la suma de las seis frecuencias sea exactamente n.
