Reto de diseño · Horas de vida

Convierte una idea sencilla en entrada, proceso y salida.

Objetivo

Aplicar el contenido del módulo en un problema pequeño que puedas explicar, modificar y probar. No se busca copiar una solución terminada: primero diseña el algoritmo y después implementa.

Antes de programar

Pseudocódigo 
INICIO
    LEER edad
    dias <- edad * 365
    horas <- dias * 24
    MOSTRAR dias, horas
FIN

Punto de partida en Python

Python 
edad = int(input("¿Cuántos años tienes? "))
dias = edad * 365
horas = dias * 24
print(f"Has vivido aproximadamente {dias} días")
print(f"Eso equivale a {horas} horas")

Modifica el programa; agrega validaciones y prueba casos que no estén incluidos en el ejemplo.

Casos de prueba

Prueba con edad = 18. Después modifica el algoritmo para aproximar minutos.

Entrega / evidencia

  • Código Python ejecutable.
  • Al menos tres casos de prueba.
  • Una explicación breve del algoritmo usado.
  • Una mejora propia respecto al punto de partida.
