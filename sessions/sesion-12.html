Del algoritmo a Python

Algoritmo · Pseudocódigo
INICIO
    contador_seis <- 0
    REPETIR 1000 VECES
        dado <- ALEATORIO(1, 6)
        SI dado = 6 ENTONCES
            contador_seis <- contador_seis + 1
        FIN SI
    FIN REPETIR
    MOSTRAR contador_seis
FIN
Python · Ejemplo / punto de partida
import random
seises = 0
for _ in range(1000):
    dado = random.randint(1, 6)
    if dado == 6:
        seises += 1
print(f"Salió 6 un total de {seises} veces")
