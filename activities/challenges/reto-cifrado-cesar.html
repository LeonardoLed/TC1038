Reto · Cifrado César

Cifra y descifra mensajes recorriendo caracteres.

Objetivo

Aplicar el contenido del módulo en un problema pequeño que puedas explicar, modificar y probar. No se busca copiar una solución terminada: primero diseña el algoritmo y después implementa.

Antes de programar

Pseudocódigo 
INICIO
    LEER mensaje, desplazamiento
    resultado <- ""
    PARA cada letra EN mensaje HACER
        SI letra es alfabética ENTONCES
            nueva <- desplazar(letra, desplazamiento)
            resultado <- resultado + nueva
        SINO
            resultado <- resultado + letra
        FIN SI
    FIN PARA
    MOSTRAR resultado
FIN

Punto de partida en Python

Python 
mensaje = input("Mensaje: ")
desplazamiento = 3
resultado = ""
for letra in mensaje:
    # TODO: desplaza letras; conserva espacios y signos.
    resultado += letra
print(resultado)

Modifica el programa; agrega validaciones y prueba casos que no estén incluidos en el ejemplo.

Casos de prueba

Entrega / evidencia

  • Código Python ejecutable.
  • Al menos tres casos de prueba.
  • Una explicación breve del algoritmo usado.
  • Una mejora propia respecto al punto de partida.
