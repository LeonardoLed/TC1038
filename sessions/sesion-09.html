Del algoritmo a Python

Algoritmo · Pseudocódigo
INICIO
    secreto <- ALEATORIO(1, 100)
    intento <- -1
    MIENTRAS intento != secreto HACER
        LEER intento
        DAR PISTA
    FIN MIENTRAS
    MOSTRAR "Correcto"
FIN
Python · Ejemplo / punto de partida
import random
secreto = random.randint(1, 100)
intento = -1
while intento != secreto:
    intento = int(input("Tu intento: "))
    if intento < secreto:
        print("Más alto")
    elif intento > secreto:
        print("Más bajo")
print("¡Correcto!")
