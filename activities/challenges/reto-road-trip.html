Reto de ingeniería · Road Trip

Calcula combustible, costo y duración de un viaje.

Objetivo

Aplicar el contenido del módulo en un problema pequeño que puedas explicar, modificar y probar. No se busca copiar una solución terminada: primero diseña el algoritmo y después implementa.

Antes de programar

Pseudocódigo 
INICIO
    LEER distancia, rendimiento, precio_litro
    litros <- distancia / rendimiento
    costo <- litros * precio_litro
    MOSTRAR litros, costo
FIN

Punto de partida en Python

Python 
distancia = float(input("Distancia (km): "))
rendimiento = float(input("Rendimiento (km/L): "))
precio = float(input("Precio por litro: "))
litros = distancia / rendimiento
costo = litros * precio
print(f"Necesitas {litros:.2f} L; costo aproximado: ${costo:.2f}")

Modifica el programa; agrega validaciones y prueba casos que no estén incluidos en el ejemplo.

Casos de prueba

Prueba 200 km, 14 km/L y $24.50/L. Verifica el cálculo manualmente.

Entrega / evidencia

  • Código Python ejecutable.
  • Al menos tres casos de prueba.
  • Una explicación breve del algoritmo usado.
  • Una mejora propia respecto al punto de partida.
