Del algoritmo a Python

Algoritmo · Pseudocódigo
INICIO
    LEER edad
    dias <- edad * 365
    horas <- dias * 24
    MOSTRAR dias, horas
FIN
Python · Ejemplo / punto de partida
edad = int(input("¿Cuántos años tienes? "))
dias = edad * 365
horas = dias * 24
print(f"Has vivido aproximadamente {dias} días")
print(f"Eso equivale a {horas} horas")

Casos de prueba / comprobación

Prueba con edad = 18. Después modifica el algoritmo para aproximar minutos.
