Del algoritmo a Python

Algoritmo · Pseudocódigo
INICIO
    LEER resistencia
    SI resistencia > 0 ENTONCES
        LEER voltaje
        corriente <- voltaje / resistencia
        MOSTRAR corriente
    SINO
        MOSTRAR "Resistencia inválida"
    FIN SI
FIN
Python · Ejemplo / punto de partida
resistencia = float(input("Resistencia (ohms): "))
if resistencia > 0:
    voltaje = float(input("Voltaje (V): "))
    corriente = voltaje / resistencia
    print(f"Corriente: {corriente:.2f} A")
else:
    print("La resistencia debe ser positiva")

Casos de prueba / comprobación

Prueba resistencia = 10 y resistencia = 0.
