Simulación · ¿Es justo el dado?

Simula lanzamientos y cuenta resultados.

Objetivo

Aplicar el contenido del módulo en un problema pequeño que puedas explicar, modificar y probar. No se busca copiar una solución terminada: primero diseña el algoritmo y después implementa.

Antes de programar

Pseudocódigo 
INICIO
    contador_seis <- 0
    REPETIR 1000 VECES
        dado <- ALEATORIO(1, 6)
        SI dado = 6 ENTONCES
            contador_seis <- contador_seis + 1
        FIN SI
    FIN REPETIR
    MOSTRAR contador_seis
FIN

Punto de partida en Python

Python 
import random
seises = 0
for _ in range(1000):
    dado = random.randint(1, 6)
    if dado == 6:
        seises += 1
print(f"Salió 6 un total de {seises} veces")

Modifica el programa; agrega validaciones y prueba casos que no estén incluidos en el ejemplo.

Casos de prueba

Ejecuta con 10, 100, 1,000 y 10,000 lanzamientos. Compara.

Entrega / evidencia

  • Código Python ejecutable.
  • Al menos tres casos de prueba.
  • Una explicación breve del algoritmo usado.
  • Una mejora propia respecto al punto de partida.
